# MaYu Brand System

## Brand Identity

MaYu is a premium realtime polling and analytics platform.

The product aesthetic combines:

- Japanese minimalism
- Wabi-sabi philosophy
- Calm realtime motion
- Editorial typography
- Elegant whitespace
- Premium SaaS analytics

The interface should feel:

- intelligent
- modern
- refined
- lightweight
- realtime
- trustworthy

Avoid:

- loud gradients
- generic startup aesthetics
- crypto-style neon visuals
- excessive glassmorphism
- cluttered layouts

# Dashboard Design Rules

# Dashboard Philosophy

The dashboard should feel:

- intelligent
- realtime
- calm
- premium

Avoid:

- crowded widgets
- overly dense data
- visual chaos

---

# Layout

Desktop:
Sidebar + Topbar + Content

Mobile:
Bottom navigation + stacked sections

---

# Sidebar

Sections:

- Dashboard
- Polls
- Analytics
- Audience
- Settings

Style:

- dark subtle sidebar
- minimal icons
- clean typography

---

# Poll Cards

Each card includes:

- poll title
- status badge
- response count
- last activity
- quick actions

Hover:

- slight lift
- subtle glow
- smooth transition

---

# Status Colors

ACTIVE:
vermillion

PUBLISHED:
moss green

DRAFT:
neutral gray

EXPIRED:
warm ash

---

# Analytics Layout

Sections:

- stats row
- response chart
- question analytics
- participation insights
- timeline analytics

---

# Charts

Use:

- Recharts

Chart style:

- minimal axes
- soft grid lines
- smooth animations
- clean labels

Avoid:

- overloaded chart colors
- giant legends
- visual clutter

---

# Realtime Feel

When new responses arrive:

- counters increment smoothly
- charts animate gently
- pulse indicator updates

Should feel alive but calm.

---

# Empty States

Empty states should:

- feel elegant
- encourage action
- use subtle illustration

Avoid generic empty dashboards.

---

# Create Poll Experience

Poll builder should:

- feel frictionless
- support drag-and-drop
- include live preview
- autosave drafts

Desktop layout:
Builder left
Preview right

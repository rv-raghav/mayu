# UI Rules

## Core Principles

1. Prioritize clarity over decoration
2. Use whitespace aggressively
3. Every component must feel lightweight
4. Avoid visual clutter
5. Realtime updates should feel smooth and calm

---

# Layout Rules

## Containers

Default container:
1280px max-width

Reading width:
860px

Analytics width:
1440px

---

# Grid

Use:

- 12-column responsive grid
- 24px gutters
- generous vertical spacing

---

# Radius System

Small:
10px

Cards:
18px

Modals:
24px

Floating buttons:
999px

---

# Shadows

Use subtle shadows only.

shadow-soft:
0 4px 20px rgba(0,0,0,0.04)

shadow-medium:
0 10px 30px rgba(0,0,0,0.08)

shadow-large:
0 20px 60px rgba(0,0,0,0.12)

Avoid aggressive shadows.

---

# Borders

Use low-contrast borders.

Preferred:
1px solid rgba(0,0,0,0.06)

---

# Buttons

Primary Button:

- vermillion background
- white text
- subtle hover darkening

Secondary Button:

- transparent
- soft border
- light hover background

Never use oversized buttons.

---

# Cards

Cards should:

- feel airy
- use large padding
- have minimal borders
- use subtle shadows

Avoid:

- thick borders
- noisy backgrounds
- excessive gradients

---

# Forms

Inputs should:

- feel spacious
- use soft borders
- have elegant focus states
- avoid heavy outlines

Focus state:

- subtle accent glow
- clean border highlight

---

# Icons

Use:

- Lucide React

Style:

- outline icons
- minimal stroke width
- consistent sizing

---

# Responsive Rules

Desktop:

- multi-column layouts
- sidebar navigation

Tablet:

- adaptive grid collapse

Mobile:

- stacked sections
- bottom navigation
- simplified charts

---

# Accessibility

Mandatory:

- keyboard navigation
- visible focus states
- semantic HTML
- aria labels
- proper contrast ratios

Minimalism is not an excuse for unusable interfaces. Humanity keeps trying this anyway.

# Component Library Rules

# Core Stack

Use:

- shadcn/ui
- Tailwind CSS
- Framer Motion
- Lucide React

---

# Button Component

Variants:

- primary
- secondary
- ghost
- danger

Primary:
vermillion background

Radius:
16px

Transitions:
smooth and subtle

---

# Card Component

Rules:

- large padding
- subtle border
- soft shadow
- spacious layout

Avoid dense cards.

---

# Modal Component

Behavior:

- centered
- blurred backdrop
- smooth fade animation

Radius:
24px

---

# Input Component

Style:

- soft borders
- clean focus states
- large padding

Focus:
accent border + soft glow

---

# Badge Component

Types:

- active
- published
- expired
- draft

Use semantic colors only.

---

# Toast Notifications

Style:

- minimal
- elegant
- subtle animation

Position:
bottom-right desktop
top mobile

---

# Navbar Component

Style:

- transparent blur
- subtle border
- sticky positioning

---

# Sidebar Component

Style:

- compact
- icon-driven
- dark subtle background

---

# Poll Components

Components:

- QuestionCard
- PollCard
- OptionItem
- ProgressBar

Question cards should:

- feel lightweight
- use large typography
- support realtime updates

---

# Analytics Components

Components:

- StatCard
- TimelineChart
- BarChart
- LiveIndicator

Animations should remain subtle.

---

# Mobile Components

Mobile rules:

- larger touch targets
- simplified layouts
- reduced chart density

---

# Loading States

Use:

- skeleton loaders
- shimmer animation
- soft opacity transitions

Avoid spinners everywhere.

Humans stare at loading spinners like confused raccoons at vending machines. Give them structure instead.

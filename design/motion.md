# Motion System

## Motion Philosophy

Animations should feel:

- intentional
- smooth
- calm
- premium

Motion should resemble:

- ink settling on paper
- soft environmental movement
- elegant transitions

Avoid:

- bouncy springs
- exaggerated scaling
- chaotic motion
- flashy transitions

---

# Motion Timing

Hover:
180ms

Card transitions:
250ms

Modal transitions:
320ms

Page transitions:
400ms

Realtime analytics updates:
500ms

---

# Preferred Animations

Use:

- opacity fades
- blur reveals
- subtle translateY
- stagger animations
- smooth number interpolation

Avoid:

- shaking
- spinning
- elastic spring physics
- excessive parallax

---

# Hover States

Cards:

- slight lift
- subtle border emphasis

Buttons:

- soft brightness adjustment
- minimal translateY

---

# Page Transitions

Use:

- opacity fade
- subtle horizontal slide

Do not use:

- large zoom transitions
- dramatic scaling

---

# Realtime Animations

Analytics updates should:

- animate smoothly
- interpolate values
- pulse gently on updates

Realtime indicators:

- subtle glowing pulse
- low intensity

---

# Scroll Animations

Use:

- staggered fade-in
- small translateY
- soft blur reveal

Avoid long cinematic animations.

Users came to create polls, not watch your GPU benchmark.
